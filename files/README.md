# Test files

`<program>/<version>/<recipe>.<ext>`: one file per recipe and twin from the CAD Fixture Recipes booklet, made in that program and version, with a `manifest.json` per set (recipe ID, program build, expected values, measured values, check result). Assemblies link the part files in the same folder.
