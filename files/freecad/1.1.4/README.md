# FreeCAD 1.1.4 fixtures, recipes v1.23

Small, known FreeCAD files made from the CAD Fixture Recipes booklet (v1.23) in FreeCAD 1.1.4: the P, S, A, and F series. Parts are PartDesign bodies with fully constrained sketches; sheet metal uses the SheetMetal add-on 0.8.26; assemblies use the built-in Assembly workbench and link the part files beside them. Every file was reopened and checked against the booklet's expected values. manifest.json lists each file's expected and measured values, its features, sketches, and joints, and the recipes left out, with a reason.
